# Gals-seildel-C

## 📜 Origem e História do Projeto

Este código nasceu originalmente em **2011**, durante a minha época de Engenharia de Computação no IFCE. 

Ficou guardado por anos como um arquivo `.zip` esquecido na minha caixa de e-mails, até que, há cerca de 5 anos, resolvi resgatá-lo e subri-lo para o GitHub exatamente do jeito que estava.

Agora, impulsionado pela ideia (quase mirabolante) de revisitar a linguagem C e aprofundar nos fundamentos de baixo nível, tive o *insight* de voltar a este repositório para mexer nas teias de aranha do código, organizar a casa e aplicar os conceitos modernos de refatoração.


> **Nota de rodapé (Setembro de 2026):**  
> Tentando refatorar este código e relendo a ideia de código cavernosa que tive anos atrás. 😅
